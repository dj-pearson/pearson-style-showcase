## Codebase Patterns

### Tech Stack
- React 18 + TypeScript + Vite 6 + Tailwind CSS 3 + shadcn/ui
- Supabase (PostgreSQL + 24 Edge Functions in Deno)
- TanStack Query v5 for server state
- React Router v6 with lazy loading
- Three.js + GSAP for 3D/animations
- Vitest + Testing Library for tests

### Project Structure
- Components: src/components/ (PascalCase, functional + hooks)
- Pages: src/pages/ (lazy-loaded via React.lazy)
- Hooks: src/hooks/ (camelCase with use prefix, 16 total)
- Lib: src/lib/ (21 utility modules)
- Edge Functions: supabase/functions/ (24 functions, Deno runtime)
- Shared edge utilities: supabase/functions/_shared/
- Tests: src/**/__tests__/ pattern
- Database: supabase/migrations/ (42 migration files)

### Import Pattern
- Always use @/ alias (e.g., @/components/ui/button)
- Never use deep relative imports

### Build & Dev
- Dev server: npm run dev (port 8080)
- Build: npm run build (Vite, output to dist/)
- Test: npm test (Vitest)
- Lint: npm run lint (ESLint)
- Deploy: Cloudflare Pages from main branch

### Key Conventions
- Functional components only (no class components)
- TypeScript strict mode enabled
- Supabase types auto-generated (DO NOT edit src/integrations/supabase/types.ts)
- shadcn/ui components in src/components/ui/ (copy-paste, not npm)
- Tailwind-first styling with cn() utility for conditional classes
- React Hook Form + Zod for forms
- DOMPurify for HTML sanitization
- Logger utility (src/lib/logger.ts) instead of console.log

### Security Modules
- src/lib/security.ts - Input validation and sanitization
- src/lib/secure-cache.ts - AES-GCM encrypted localStorage
- src/lib/session-rotation.ts - Automatic token rotation
- src/lib/device-trust.ts - Device fingerprinting
- src/lib/csrf.ts - CSRF token management
- supabase/functions/_shared/rate-limiter.ts - Edge function rate limiting

### Iteration 1 - Critical Platform Improvements
**Date**: 2026-03-07
**Branch**: claude/critical-platform-improvements-H67AO
**Stories Completed**: 4

#### US-026: Fix XSS vulnerabilities in MarkdownRenderer [PASSED]
- Hardened custom syntax parser ([button:], [alert:], [badge:]) with URL validation at parse time
- Replaced `button` HTML elements with `span[data-custom-btn]` to prevent onclick injection
- Added whitelist validation for style, type, and variant attributes
- Added img src validation blocking data:image/svg and javascript: protocols
- Post-sanitization img src check in CustomHTMLRenderer
- Text content sanitized through DOMPurify before rendering

#### US-027: Fix session rotation race condition [PASSED]
- Replaced in-memory `pendingRotation` flag with localStorage-based distributed lock
- Lock includes tab ID and timestamp with 30-second timeout for hung rotations
- Read-after-write verification prevents race between concurrent tab lock acquisitions
- Inter-tab communication via `storage` event listener syncs rotation state
- Failed rotations explicitly preserve previous session token (no invalidation)
- Cleanup of lock and listeners on logout

#### US-028: Harden OAuth state parameter [PASSED]
- OAuth state now cryptographically bound to CSRF token + provider name + redirect URL via SHA-256 hash
- State format: `{random}.{bindingHash}` where hash covers all binding parameters
- Provider mismatch verification prevents cross-provider state reuse attacks
- 5-minute retention period replaces immediate clearing (handles slow redirects)
- CSRF token generation updated: `crypto.getRandomValues()` replaces predictable `Date.now().toString(36)`
- AuthCallback.tsx updated for async verification flow
- Backward-compatible: legacy states without provider binding still verify via timing-safe comparison

#### US-024: Add comprehensive error boundaries and fallback UI [PASSED]
- Created `RouteErrorBoundary.tsx`: per-route error element with Try Again / Go Home recovery
- Created `SuspenseFallback.tsx`: skeleton loading UI matching typical page layout
- Created `HeroErrorBoundary.tsx`: lightweight boundary for Three.js/GSAP with static gradient fallback
- All lazy-loaded routes in App.tsx wrapped with `errorElement={<RouteErrorBoundary />}`
- Suspense fallback replaced with SuspenseFallback component
- HeroSection and Interactive3DOrb wrapped with HeroErrorBoundary in Index.tsx
